Comment ça fonctionne ?

  1. Installez le package via pip install local-ai-hardware-scanner.
  2. Lancez le service : local_ai_scanner --run.
  3. Le scanner analyse votre matériel et génère un rapport JSON.
  4. Consultez les recommandations et téléchargez le modèle adapté.

FAQ

Quel OS est supporté ?

Linux, Windows et macOS. Le script détecte automatiquement les pilotes GPU.

Le scanner consomme‑t‑il beaucoup de ressources ?

Non, il s’exécute en moins d’une seconde et utilise moins de 5 % du CPU.

Puis‑je l’utiliser dans un conteneur Docker ?

Oui, une image officielle est disponible sur Docker Hub.
